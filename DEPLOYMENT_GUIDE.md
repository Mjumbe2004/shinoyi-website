# GitHub Pages Deployment Guide

## Your Website is Ready for Deployment! 🚀

Your secondary school website is now ready to be deployed to GitHub Pages. Follow these simple steps:

### Step 1: Enable GitHub Pages

1. Go to your repository: https://github.com/Mjumbe2004/shinoyi-website
2. Click on **Settings** (top menu)
3. Scroll down to **Pages** section (left sidebar)
4. Under "Source", select:
   - Branch: **main**
   - Folder: **/ (root)**
5. Click **Save**

### Step 2: Wait for Deployment

GitHub will automatically deploy your website. This usually takes 1-2 minutes.

### Step 3: Access Your Live Website

Once deployed, your website will be available at:

**https://Mjumbe2004.github.io/shinoyi-website/**
