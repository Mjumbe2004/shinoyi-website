# Secondary School Website

A comprehensive informative website for a secondary school with login functionality for students, teachers, and parents.

## Features

### Public Pages
- **Homepage**: School information, programs, contact details
- **About Section**: School mission, teacher dedication, parent partnership
- **Programs**: Science, Mathematics, Languages, Social Studies, Sports, Arts
- **Contact Information**: Address, phone, and email

### Authentication
- **Login System**: User type selection (Student, Teacher, Parent)
- **Sign Up**: Create new accounts with validation
- **Session Management**: Secure session storage

### Student Dashboard
- View grades and academic performance
- Check pending assignments
- Attendance records
- Class schedule
- Messages from teachers
- Current GPA and academic statistics

### Teacher Dashboard
- Manage multiple classes
- Grade management system
- Create and assign assignments
- Mark attendance
- Send messages to students
- Office hours and class details

### Parent Dashboard
- View child's profile
- Monitor grades and performance
- Check attendance records
- Progress reports
- Contact teachers
- View child's class information

## How to Use

1. **Clone or download** the repository
2. **Open `index.html`** in a web browser
3. **Navigate through** the website using the menu
4. **Click "Login"** to access the dashboard with demo credentials
5. **Select your user type** (Student, Teacher, or Parent)
6. **Log in** with the demo credentials provided above
